# Bacias que abastecem Rio Preto — geoportal

Uso do solo (MapBiomas) e qualidade da água (CETESB) nas 7 ottobacias de nível 5 que abastecem a região de São José do Rio Preto (SP). Projeto pessoal de portfólio, feito somente com **dados públicos**. Não representa o SeMAE nem qualquer órgão público.

Site: https://leonardopelais.github.io/geoportal-bacias-rio-preto/

| Pasta | Versão | Descrição |
|---|---|---|
| [`leaflet/`](leaflet/) | Leaflet (feita à mão) | Painel de análise por bacia e estação, uso do solo 1985 × 2024, séries históricas, busca. [README](leaflet/README.md) |
| [`qgis2web/`](qgis2web/) | qgis2web | Exportação do projeto QGIS com ajustes manuais. [README](qgis2web/README.md) |

Resultados são **associações**, não causalidade. A rede de monitoramento não mede agrotóxicos.
